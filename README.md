🎓 Chandigarh University MCA - Web Programming (26CAT-604)

An interactive, single-page, last-minute revision guide tailored specifically for Master of Computer Applications (MCA) students at Chandigarh University (CU).

This repository contains consolidated study materials and quick-recall notes for Web Programming (Course Code: 26CAT-604), focusing strictly on Unit 1: HTML Foundations & Introduction to CSS.

🚀 Interactive Application Features

Instead of a boring PDF, this guide is built as a responsive web application to help you study faster:

Interactive Chapter Navigation: Jump straight to specific syllabus topics like Formatting, Forms, or Responsive Design.

High-Yield Comparisons: Differentiates easily confused tags that often appear in CU exams (e.g., <b> vs <strong>, GET vs POST).

Self-Test Flashcards: Interactive drop-downs for essential exam questions. Test your memory before revealing the answer.

Master Tag Bank: A quick-recall table of all essential HTML tags and CSS properties you need to memorize.

Day-Before-Exam Checklist: A persistent, interactive checklist to track your revision progress (saves locally in your browser).

Print-Ready: The CSS includes print media queries, allowing you to easily save it as a clean, sidebar-free PDF for offline reading.
