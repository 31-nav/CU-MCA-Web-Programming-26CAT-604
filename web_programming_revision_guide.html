START HERE HTML Document Essentials

  • <!DOCTYPE html> declares the document type/version.
  • <html> wraps the whole document.
  • <head> holds document information (not shown on the page).
  • <title> names the browser tab/page.
  • <body> contains all visible content.

Tag Rules

Container (paired) tags have an opening and closing tag, e.g. <b>text</b>. Nested tags must close inner-to-outer.

Empty tags are single, self-closing instructions, e.g. <br> and <hr>.

Attributes add information inside an opening tag, generally as name="value" pairs.

Headings <h1> to <h6> create a heading hierarchy for structure, not just bigger text.

Comments use <!-- comment -->. They document source but are never rendered.

index.html 
<!DOCTYPE html>
<html>
<head>
    <title>My Page</title>
</head>
<body>
    <h1>Heading</h1>
    <p>A paragraph.<br>Same block, new line.</p>
    <!-- this comment is invisible on the page -->
</body>
</html>

Chapter 1.1 & 1.2: Text, Lists & Hyperlinks

Formatting Text

Visual tags change appearance only; semantic tags also communicate meaning to browsers, search engines, and assistive technology.

<b> vs <strong>

Both render as Bold text. strong also signals importance.

<i> vs <em>

Both render as Italic text. em also signals emphasis.

Exam Cue

If asked to "differentiate b and strong" or "i and em": both pairs look identical on screen, but the second tag in each pair also carries semantic meaning for screen readers and search engines.

Other tags: <mark> (highlight), <u> (underline), <strike> / <del> (strikethrough), <tt> (monospace), <sub> / <sup> (sub/superscript), <big> / <small> (relative sizing).

Hyperlinks

<a href="url">link text</a> creates a link. The target attribute controls opening:

_selfSame tab/frame (default)
_blankNew tab or window
_parentParent frame
_topFull window, breaking frames

A same-page bookmark is made by giving the destination an id, then linking to it with href="#id".

Chapter 1.2 & 1.3: Images, Tables & Media

Images

<img> references an image file. Key attributes:

  • src: path to the image
  • alt: description/fallback text (important for accessibility)
  • width / height: dimensions
  • usemap: links image to a clickable map

Audio and Video

Tags: <audio>, <video>, <source>, <embed>, <track>.

Why multiple sources? <source> supplies a media file; multiple elements let the browser fall back to another format if the first fails.

controls autoplay loop muted poster (video)

Embedding

<iframe> embeds another HTML page inside the current page - the modern replacement for old-style frames.

Tables

Core structure: <table>, <tr> (row), <th> / <td> (header/data). <caption> gives a title.

cellpaddingSpace between cell content and border
cellspacingSpace between adjacent cells
colspanMerges a cell across multiple columns
rowspanMerges a cell vertically across rows

  <tr>
    <td rowspan="2">Unit 1</td>
    <td>45</td>
  </tr>
  <tr><td>48</td></tr>
</table>

Image Maps & Graphics-Based Navigation

Places multiple clickable regions on a single image. Common for graphical nav bars.

<img usemap="#mapname"> Displays the image and links it to a map
<map name="mapname"> Container for the clickable regions
<area> Defines one clickable region (shape, coords, href)

Memory Cue

img usemap attaches image to map ➔ map area defines clickable regions ➔ shape + coords says where ➔ href says where it goes.

Chapter 1.3: Forms & Controls

Syllabus-Highlighted

Form Structure & Methods

Forms collect visitor data. action identifies where submitted data is sent.

High-Yield Comparison

GET

Appends values to the URL. Visible in address bar, used for non-secure data.

POST

Sends data inside the HTTP request body. Not shown, used for secure data.

readonly vs disabled

readonly is submitted. disabled is not submitted.

radio vs checkbox

Radio allows one choice (if same name). Checkbox allows multiple.

Attributes & Validation

value: Initial value size: Visible width maxlength: Max chars min / max: Legal numeric limits multiple: Multiple values allowed pattern: Regex validation required: Compulsory field

New HTML5 Input Types

  • email Expects/validates email address
  • number Numeric spinner; pairs with min/max/step
  • date Date picker control
  • range Slider control for values in a range
  • color Colour-picker control
  • search Styled/behaving as a search box
  • url Expects/validates a web address

Core elements: form, input, textarea, select, option, button, label, fieldset, legend.

Chapter 1.4: Frames & Responsive Design

Legacy

Traditional Frames

Divides a browser window into separate contexts. <frameset> replaces <body> (rows/cols).

IMPORTANT: Not supported in HTML5. Replaced by <iframe> and <div> + CSS. Limitations: poor small-screen fit, resolution issues, back-button errors, poor SEO.

Division-based Layouts

<div> is a generic block-level container with no default appearance. Combined with CSS (widths, floats, flexbox/grid), divisions build layouts replacing old frames.

HTML Responsive Web Design

Makes a page adapt its layout to different screen sizes instead of using one fixed layout.

1. Viewport Meta

<meta name="viewport" content="width=device-width, initial-scale=1.0">

Matches page width to device width.

2. Fluid Layout & Images

Relative units (%, em, rem) so elements resize.

max-width: 100%

Lets images shrink to fit containers.

3. Media Queries

CSS rules applied based on conditions (e.g. screen width).

@media (max-width: 600px) { .card { flex-direction: column; } }

Chapter 1.5: Intro to CSS

CSS separates presentation from HTML content, letting one definition control the look of many pages consistently.

Syntax & Application

selector { property: value; }

Three ways to add CSS:

  • Inline: style attribute on one element
  • Internal: <style> block in the head
  • External: <link rel="stylesheet" href="style.css">

Self-Test: Exam Questions

Click a question to reveal the answer. Try to answer from memory first!

1. Explain HTML document structure.
DOCTYPE declares the type; html wraps the document; head stores information; title names the page; body shows visible content.
2. Differentiate paired and empty tags.
Paired tags have opening/closing tags and content between them. Empty tags are single instructions, such as br/hr.
3. Differentiate p and br.
p creates a paragraph block; br inserts one line break inside a block.
4. Differentiate ul, ol, and dl.
ul gives bullets; ol gives an ordered/numbered sequence; dl holds terms and their descriptions.
5. Explain href and target.
href gives the link's destination; target controls where it opens (e.g. _self, _blank).
6. Why is alt important?
It describes an image for accessibility and displays if the image fails to load.
7. Explain the core table tags.
table defines the table; tr is a row; td a data cell; th a header cell; caption gives the title.
8. Differentiate colspan and rowspan.
colspan merges cells horizontally across columns; rowspan merges cells vertically across rows.
9. Differentiate GET and POST.
GET shows submitted values in the address bar; POST sends data inside the HTTP request body.
10. Differentiate readonly and disabled.
readonly cannot be edited but is still submitted; disabled is unusable and is not submitted.
11. Name the new HTML5 input types covered.
email, number, date, range, color, search, and url.
12. Why use multiple source elements in audio/video?
So the browser can try the next source file if it cannot play the first.
13. What is an image map?
A single image with multiple defined clickable regions, each linking to a destination.
14. What do shape and coords do in an area tag?
shape sets the region's geometry (rect/circle/poly/default); coords positions that shape on the image.
15. Why are traditional frames not recommended?
Unsupported in HTML5 and cause usability, small-screen, back-button, compatibility, and SEO issues.
16. What is responsive web design, and how is it achieved?
A page layout that adapts to screen sizes, achieved through a viewport meta tag, fluid/relative units, flexible images, and CSS media queries.
17. Why do we need CSS?
It separates content from presentation, allowing consistent, reusable, and easily maintainable styling across many pages.
18. Name the three ways to apply CSS.
Inline (style attribute), internal (style block in head), and external (linked .css file).
19. List the box model layers (inside to outside).
Content, padding, border, margin.
20. What does z-index control?
The stacking order of overlapping positioned elements - higher values appear on top.
21. What does float do, and its traditional use?
It pushes an element left or right and lets content flow around it; traditionally used for page/navigation layout.
